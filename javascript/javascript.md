# GDG 基礎 JavaScript 實作工作坊：3 小時課程規劃與細流

## 一、 基本資訊

* **課程名稱**：JavaScript 基礎程式介紹
* **授課時數**：至多 3 小時
* **主要講師**：婷婷姊姊
* **課程難度**：入門 （具備 C、Python 或是各種程式設計基礎概念者更佳）

## 二、 課前準備與環境要求

### 1. 學員環境準備（需於課前完成）

* **作業系統**：Windows / macOS / Linux 均可
* **編輯器**：Visual Studio Code
* **必裝擴充套件**：[Live Server (Ritwick Dey)](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer&utm_source=gemini)
* **瀏覽器**：Google Chrome（或是任何具備開發者工具可用於 Console 操作）

### 2. 檔案與教材分發方式

* **上課教材與範例 Repo**：

  * [GitHub 存放庫連結](https://github.com/citycafe578/citycafe_courses/tree/main/javascript?utm_source=gemini)
* **課堂投影片**：提供線上投影片連結及現場 QR Code 掃描，上課前會更新至 GitHub
* **即時提問互動**：Slido
* **課堂檔案下載**：

  * 學員課前直接至 GitHub 下載 ZIP 檔案至本機解壓縮。
  * 助教於課前 15 分鐘協助尚未完成安裝環境與下載檔案的同學。

## 五、 講師與助教協作備忘

1. **助教配置**：

   * 建議現場配置至少 1\~2 位助教。
   * 特別防範：Live Server 啟動失敗、檔名路徑引入錯誤、打錯大寫 `Number()` 或保留字拼錯等常見又白癡又不好找的錯誤。
2. **節奏控制指引**：

   * 若進度延遲，單元 6 的 DOM 事件監聽可聚焦在單純的 `click` 與 `dblclick`，其餘事件僅保留投影片供學員自學。
